## 改了什么，以及收益为何有边界

仅修改共用 `replaceFile` 入口：对 Claude、WorkBuddy、ZCode、OpenCode 完整解析来源，逐个比较 29 个标准化持久字段。旧事实必须占据全局 ID 末尾连续区间，且完整替换会分配相同 ID，才保留旧行、只插入新后缀。读取和核对是一条条进行，不建立全来源事件数组。

这个 ID 条件保住原有按插入顺序累加的金额精度，不能只凭 token 总量相同保留旧行。非末尾来源、ID 缺口、绑定改变、冷历史／归档、进度／额度状态、扩展事件列及未知持久来源触发器走原完整替换。解析中发现旧字段修订、删除或顺序变化时，回滚后重新走原替换；异常路径可能多解析一次。事务、回滚后的缓存清理、警告和来源元数据语义均保留。

**这是增量发布，原始输入仍完整读取。** 没有新增表、schema 迁移、依赖、配置开关或堆额度。不是四来源真正增量续读，也不是多年历史容量验收。

下面统计的是每次第二追加从落地到页面完成之间的**全部同种来源提交调用**，包括重复核对和关联子文件；事件 INSERT／UPDATE／DELETE 通过现有事实 revision 计数，不将派生表写入算入。
