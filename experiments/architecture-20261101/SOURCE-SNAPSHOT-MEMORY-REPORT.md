## 改了什么

`syncRound`原来保留全部旧来源行，只供后续消失文件的改名判断使用。现在仍逐行检查全部来源，仅保留本次没有发现的旧路径；失败home仍参与歧义判断，快照仍取同步开始时的所有权。来源读取、SHA、解析、事实事务、查询、价格及发布逻辑不变。没有应用上一卡被封存的归档证明生命周期补丁。没有增加堆、缓存、表、依赖或常驻进程。

实际两年私有库29,291来源的只读归因：旧快照存活堆27.399MiB，候选0.113MiB，读取217→35ms；这里的GC仅用于归因，未加入产品或正式计时。完整页面资源以表中成对结果为准。真正大量缺失路径时仍需保存这些路径，发现和检查仍随来源数量增长。
