# Q6 逐文件能力与目录初始化修复

日期：2026-11-05。状态：修复、固定性能矩阵及最终回归已收口，阶段提交后停止等待反馈。**原生普通刷新及密度增长通过本轮方向/刷新门；文件数增长、切换及初始化仍有未达标项，不是整体性能验收通过。**

## 改动

把“能证明哪些文件改变了”和“能只解析一个文件的尾部”分开。合法的大帧 DSH 文件保留既有完整解析，记录为 full-only；它改变时只重读自身，不再阻止其他文件增量采集，也不反复重建整个来源清单。完整解析仍验证实际读取区间，变化期间失败会回滚。

首次登记受管目录的完整身份，包括空目录；后续用对象及父目录身份判断来源归属。无需解析无关的、已经消失或不可访问的系统临时对象。新文件、目录移入/移出、别名、缺失根目录、失效日志及不完整覆盖仍触发完整检查。清单本身被修改会撤销 ready，事务回滚会恢复它。

原生助手仅从目录返回列表中过滤纯 CLOSE 记录；混合内容、删除和改名记录保留，读取字节及记录预算没有放宽。初始化对固定截点补处理一次，补处理期间再来的写入留给下一轮。服务重开的随机关闭令牌不再使来源身份失效。

继续使用现有事实、解析器、检查点、事务、派生视图和发布机制；没有增加事实表、依赖、常驻进程或堆预算。安装中的助手没有替换。

本轮原生性能使用私有目录中编译的新版助手。现有服务及安装中的旧助手尚未应用这些成果；正式启用仍需部署相应二进制并重开服务，本轮只交付已验证的源码和本地提交。

## 测量口径

冻结 Q5 对照与本轮候选，私有证据在 `output/architecture-20261105/q6/q6-20261105-d/`。主对照每格两次 Codex、两次 DSH；输入写入完成到原页面正确新值的帧回调为主指标，探针确认另外保存。初始和最终业务、records、metadata、period comparison 逐值比较。单格样本很少，不宣称长期中位数或 p95。

原生组来源及辅助输入在 C 盘，数据库在 E 盘；SHA 组保留完整前缀校验。只在同模式、同布局的新旧版本之间比较，不从跨卷差异推导速度结论。使用既有事实种子和备份，保留原始文件已不存在的历史；本轮没有真实历史的空库重建。

1×/10× 仍是同一文件/日期/会话分布内的密度增长：146,412 / 1,464,120 条初始事实、1,968 个用量文件，不能代表一年/两年历史。独立文件数小夹具固定为 20,001 条事实、两个会话，只改变文件分布，准备成本另计。

先前 c 目录的候选与限量初始化诊断均在 ready 前停止，零次计时追加；它们用于定位无关卷对象，不并入 d 矩阵。文件数准备第一次因输出父目录缺失而停止，尚未生成样本，原始错误独立保存。

## 保留的限制

文件数对照固定为每种来源每格一次，四格共八次追加，没有补样：

- 约 2 千文件：Q5 Codex / DSH 为 0.633 / 0.587 秒，候选 0.279 / 0.128 秒。
- 约 2 万文件：Q5 为 3.594 / 3.483 秒，候选 0.490 / 0.344 秒。候选没有全局回退，但两次都实际采用带原生证明的**单文件重解析**，分别读取 1,505 / 433 字节；不能记为成功尾部增量。约 2 千文件组则为真实尾部增量。
- 候选数值比为 Codex 1.76、DSH 2.68，**≤1.3 的文件数增长目标未过**。两组解析路径不同，样本各一次，也不能把差额全部归因于文件数或用它推导稳定增长曲线。1×→10× 真实数据密度组比值为 1.027 / 0.996，通过该项小样本目标。
- 合成种子准备分别约 30.9 / 316.5 秒；共用 Q5 原解析器创建，固定 20,001 条事实及两个会话。准备中并行运行过约数秒的类型/lint/小恢复检查，准备数字只记账、不用于性能排名。没有额外真实历史空库重建。
- 文件数组首次打开到 all：约 2 千文件 Q5 / 候选 1.737 / 7.910 秒，约 2 万文件 5.909 / 64.421 秒。首次初始化仍随文件数增长，本轮没有解决。

常用范围切换仍未达到 200 ms。候选三次切换的组内中位数：1× 原生 460 ms、10× 原生 1,032 ms、1× SHA 493 ms、10× SHA 1,178 ms。这是点击到确认正确值的工具口径，不能冒充专用帧回调；未通过严格目标。

首次打开到 all 与重开也没有提速。1× 原生初次 Q5/候选为 4.070 / 8.670 秒，10× 为 14.951 / 43.197 秒；原生重开分别为 3.279 / 4.275、4.058 / 7.270 秒。10× SHA 初次为 17.879 / 29.002 秒，重开为 4.075 / 47.909 秒。包含浏览器启动、默认页与 all 准备，没有清空操作系统缓存，既不是空库重建，也不是来源检查单项计时。已有最小插桩不足以完整归因这些差异；不得把它们归咎于目录登记，或写成没有初始化退化。

逐文件 full-only 是正确性回退，变化频繁时自身仍可能慢；本轮普通追加选中的 DSH 是可增量文件，大帧路径另由回归验证。其余 harness 改变、拓扑不明、卷不支持等仍使用完整检查。

## 资源与核对

主对照八格 32 次追加，文件数四格八次追加，实际合计 **40 次追加、24 次专门计时切换、8 次服务重开，0 次真实历史空库重建**。12 格均完成，初始/最终共 12 组业务对拍通过，40 次正确新值、事件数及 SSE 检查通过，八次重开总量正确。候选 12 次原生追加全部没有全局回退；其中上述文件数大格两次为单文件重解析，另外十次为尾部增量。SHA 八次候选追加走既有全检查，这是预期回退，不能混入原生命中率。

gateway 512 MiB、executor 224 MiB / semi-space 4 MiB 不变。包括首次打开及独立重开采样段，候选服务树活动峰值最大 **323.37 MiB**，来自约 2 万文件初始化；真实数据候选各格最大 234.61 MiB。浏览器单列，候选最大约 **1.03 GiB**。活动峰值未超过 512 MiB；未单独测稳定空闲，不能判定 256 MiB 空闲门通过。

资源没有只计算追加：10× 原生整个采样段的服务 CPU 观测增量约 31.64 秒，逻辑读/写约 14.92 / 4.41 GiB；10× SHA 为 68.16 秒、51.91 / 4.63 GiB。包含首次初始化、四次追加、切换和重开，不是单次追加或物理磁盘 I/O。短生命周期进程可能漏采。主对照真实目录清单/索引约 1.84 MiB，约 2 万文件为 17.69 MiB，随来源数量增长。完整 WAL/状态/临时文件峰值保留在逐段资源 JSON；旧 allocatedBytes 是 GetCompressedFileSize 口径，目录可见临时零字节不代表匿名 SQLite 为零。

冻结基线 109 个文件、候选 111 个文件均逐一核对；当前 110 个生产运行文件与候选快照一致，安装中的助手与基线一致。12 个独立可写实验输入逐字节恢复。20 份资源报告中的 342 个 PID / 精确创建时间身份审计通过，无遗留实验进程；被系统服务复用的 PID 另行排除，没有终止其他进程。
