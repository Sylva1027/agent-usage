CPU 为本组全部 Node 生命周期累计核秒，包含初始打开、三次变更、切换、重开及关闭，非单次刷新。逻辑 I/O 按进程身份汇总已观察到的累计高水位，不丢弃首次采样前的计数；**是下界，不是完整物理磁盘流量**。CIM 树刷新间隔 3 秒，部分短命执行器未被 I/O 采样捕获，但退出内存／堆参数记录存在。
