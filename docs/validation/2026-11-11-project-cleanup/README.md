## 删除与保留边界

- 已结束的一年／两年容量数据、测试归档包和工作数据库，在用户对 **47,215 个文件、151.66 GB** 的具体清单明确批准后删除。保留生成代码和结果；这些旧实验现场已不能直接继续运行，需要重新准备。
- 用户另行批准删除 **795 个 Git 附件：732 张截图和 63 份日志**。同时清理 17 份浏览器自动生成的页面快照；这些已提交过的附件可从本次清理前的 Git 历史恢复。没有改写 Git 历史来抹除它们。
- 清除了 `.codex-usage`、`output`、`docs/validation`、预览目录、旧 `dist` 等处的临时产物。旧验证正文保留，并处理了指向已删除附件的链接。
- 保留正式 `public` 资源、40 张线稿原图、README 展示图、用户设计参考图、哈希绑定的视觉测试基准、源码及已有未提交计划。
- 保留原始捕获、含上游已删除记录的历史索引及真实升级备份。这些不是可由当前来源完整重建的测试垃圾。

较大的历史 JSON/CSV/TXT 记录现以原路径加 `.gz` 保存。需要重跑旧分析脚本时，应先解压回原路径；现有脚本不会自动读取压缩文件。正式报告中的对应文件链接已更新。清理过程自身的大型逐文件清单也已压缩，未保留一套新的大型工作副本。
