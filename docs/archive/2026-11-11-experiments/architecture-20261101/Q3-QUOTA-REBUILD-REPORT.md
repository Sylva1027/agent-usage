## 正式改动

1. **额度结果按变更维护。** 持久保存桶计数、原始观测的精确贡献、端点支持、冲突与周期。普通追加处理变更队列和受影响的端点后缀；时钟推进只处理新变为可见的观测。执行器重开直接复用，当前与上一窗口通过索引定位，完整历史周期消费者沿用同一份结果。队列达到 4096 次操作后保守重建，不无限占用内存。
2. **首次导入采用批量构建。** 空库导入期间保留累计会话查找所需索引，将元数据查询索引放到事实导入后构建。元数据每 1024 行使用五条批量 SQL，精确保留全局及来源会话去重。已有正确索引继续保留；索引发布失败时回滚索引与进度标记，重开复用已提交事实，无须重读全部来源。

额度仍保留全历史桶选择、官方观测身份去重、无效记录遮蔽、两分钟聚类、迟到修订与删除、冲突、未来观测和旧 asOf。旧修订可能传播到较长的周期后缀，不宣称任意修订恒定耗时。当前窗口查询同时限定相关重置区间，原始精确边界判断继续生效；覆盖过期和远期端点，避免把旧观测逐条检查一遍。

## 验收中发现的来源一致性问题

完整后端回归暴露了此前来源证明中的一个假设：Windows 快速改写并恢复 mtime 后，ctime 可能相同。原先在解析后保存当前文件摘要，不能证明统计结果来自这些字节；初建及追加均有相同缺口。

修复将 JSONL 的原始输入块、DSH 的完整压缩 frame 送入解析摘要。追加从已经验证的旧前缀摘要状态恢复，新增字节边读边累计；提交前重新读取并比对，保留原有旧前缀二次检查。JSONL 未完成尾部及 DSH 无 checkpoint 的完整 frame 也参与校验。摘要不匹配即回滚事实与进度，未添加历史数组或额外工作进程。

SHA 证明升级为 v2。第一次升级会重新解析仍可访问的 v1 来源；已经缺失原始文件的历史事实继续保留。原生 USN 证明路径保持原有契约。测试覆盖这次升级，计时使用包含修复的最终版本，早期候选结果不计入最终成绩。

独立审查曾在 JSONL 初建观察到 143,933 字节文件的真实 ctime 碰撞，旧事实为 200、独立重读为 900，后续同步未更新。该旧代码实证仅保留在 worker 工具输出及验收摘要，没有完整原始日志。主代理归档的最终七项回归自然碰撞计数为零；四项真实入口回归明确适配观测时间戳，验证摘要拒绝、事务回滚及独立解析结果。不能把最终回归写成重复捕获了自然碰撞。

## 对照方法

沿用 Windows 11、i7-14700KF、约 32 GiB RAM、Node 24.19.0 和原页面。gateway 512 MiB、executor 224 MiB / semi-space 4 MiB 的参数不变。

比较三个版本：Q2 前冻结源码、最终 Q2 冻结源码、最终 Q3。两份对照分别来自 Q2 的 98 文件快照及本轮开始时的 99 文件快照，加载时校验摘要。全部 18 个镜像在认证前准备完毕，候选诊断归档后保留原始来源原位，没有新增硬链接改变来源元数据。

两种规模均包含六类来源、1,968 个用量文件及辅助文件，空库事实数分别为 146,412 和 1,464,120。原始输入约 4.27 GB / 41.83 GB，天数、文件数和会话轴固定。10× 是密度测试，不代表整套项目已经通过两年历史验收。

完整重建从独立空库读取真实来源，保留来源检查、同步和解析，直到原页面默认页及首次 all 正确绘制。每组先测两次，差异超过 5% 才补第三次。浏览器启动包含在开页计时中；服务就绪及采样器准备单列，不是物理冷盘测试，也不称正式 p95。

普通追加比较 Q2 / Q3 × 1× / 10×，每格 20 次 Codex、20 次 DSH。计时包含原始记录落地、来源检查、SSE、请求及正确新值绘制，断言事件数增加且响应不是旧摘要缓存命中。复用各自完整重建的已发布镜像，重开另验复用。

最终的九类主业务字段、元数据及周期对比逐值对拍；仅规范镜像路径、来源 id 与实际评价时间字段。额度另按相同 asOf 与独立原始算法精确对拍。金额不放宽精度，不调整事件累计顺序。
