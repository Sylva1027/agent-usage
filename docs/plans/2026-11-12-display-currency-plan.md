# 主页计价币种与汇率输入

状态：2026-11-12 已授权实施；本地实现、隔离验收及在用服务更新完成。

## 需求与实现边界

- 取消“数据里有人民币模型就自动切换纵轴”的逻辑，首次使用默认美元。
- 在计价弹窗汇率下方新增紧凑的 `计价 $ / ¥`，复用现有分段控件材质和选中效果，窄屏自动换行。
- 选择立即生效，并保存在当前浏览器；刷新、筛选和异步数据返回均不得覆盖选择。
- 四个花销卡片、时间分布纵轴、费用 tooltip、按花销详情及无障碍标签统一使用选择的币种。
- 原始 USD/CNY 金额不变，展示时按已保存汇率换算。同一模型跨原币种先换算再合并，计算保留完整精度，显示两位小数。
- 只切换显示币种不请求重新计价。汇率和模型价格仍通过“保存并重算”生效；未保存的汇率不影响主页。
- 汇率改为十进制文本输入，不出现上下调节按钮，不通过方向键或滚轮改值；保存时校验有限正数，拒绝非十进制文本。
- “立即更新”现有完整流程每次携带强制更新标记，价格与汇率并行查询，不受上次更新时间限制。手动汇率优先，自动报价仍更新；恢复自动汇率仍沿用现有按钮。
