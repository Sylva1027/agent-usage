## 本卡交付

1. **JSONL 两来源**：以有预算、可落盘的消息候选集合代替整文件常驻 Map/数组。保留 Claude 最大用量胜出、同值取首条，以及 WorkBuddy 首条有效非 Auto 记录胜出的规则。排序仍为时间戳、JavaScript `localeCompare`、稳定原顺序；末尾标题、警告及价格明细不变。
2. **SQLite 两来源**：会话元数据和去重警告不再随全库常驻内存；已有唯一 BINARY/TEXT 主键且实际键均为文本时，直接查上游索引，否则流式建立有界会话集合。用量与会话元数据在同一个只读快照内读取。保留父会话目录追溯、重复会话键、缺表与版本守护语义。不上游建表、加触发器或迁移。
3. **共同验证与交付**：公共事实库仍沿用完整替换事务及历史保留；对拍旧版本、修订/删除、重启、失败回滚及增长成本，更新六来源能力表。

这不是四来源的增量解析完成卡：更改文件/数据库仍须完整提取并替换，可靠的续读证据、持久候选状态和来源级登记留待后续。本卡不改 Codex/DSH 已交付的采集快路径、原生助手、页面或 schema。

## 验收范围与标准

| 验证 | 固定范围 | 标准 |
| --- | --- | --- |
| 适配器语义 | 四来源既有测试 + 新边界测试 | 原事件顺序、全部字段和警告精确相同，无数值容差 |
| 公共索引 | 四来源导入、追加、修订/删除、重开、失败回滚 | 与独立完整导入对拍；失败不提交半份事实；消失来源保留 |
| 快照 | 两 SQLite 来源并发修改 | 单次读取不混合两个提交版本 |
| 增长诊断 | 四来源 × 两规模 × 旧/新 = 16 次独立进程 | 固定默认 224 MiB 堆；事件摘要精确相同；报告耗时、峰值内存、临时空间和 I/O；不宣称 p95 |
| 长会话压力 | 两 JSONL 来源，含大量重复和同时间戳 ID | 能完成；候选集合和排序受固定预算约束；保持 localeCompare 与稳定序 |
| 防回退 | 公共索引/进度/业务视图相关回归及 typecheck、lint | 无本卡新增失败；记录既有失败；不重跑已接受的大型页面性能矩阵 |

小来源优先走普通 Map，大来源才落盘；避免用每次必建临时库换取表面内存下降。最终 JSONL 候选集合采用 **128 MiB 保守估算工作集**，元数据回退/警告集合采用 32 MiB；这是内部估算预算，不是新增堆额度或物理内存保证。单条合法大记录仍完整处理。默认堆维持 224 MiB + 4 MiB semi-space，实际 RSS、SQLite 缓存和临时 I/O 单独测量。

初版过早落盘并反复解码完整事件，Claude 10 万消息达 7.443 秒，未接受。修正为普通 Map、相邻候选合并写、仅排序字段参与外部合并及上游索引读取后，最终为 0.754 秒。原始 16 项保留；三轮修正分别只复测 8 个候选项、不重跑旧版，另加 2 项 30 万消息实际落盘压力，共 42 次独立进程样本。各轮分开存放，不覆盖失败样本；本卡不据此宣称稳定 p95。
