## 正式接入

- 入口和弹窗在公共 `index.html` 中，不放进 waifu 专属区块。四个公共模块／样式 `share-card-data.js`、`share-card.js`、`share-dialog.js`、`share.css` 同时进入标准版与 waifu 版 ZIP。
- 标准版提供 classic 深浅两种图片；waifu 版沿用当前皮肤、深浅模式与人物显隐，隐藏人物时保留主题色和简洁布局。公共绘图模块不导入皮肤资源，只有主页已加载人物运行时时才提供配色和素材。
- 从主页已加载的真实汇总及同期比较明细创建冻结白名单快照，继承来源筛选、时区、当前显示币种与 FX；不重新扫描日志。未知明细显示破折号，不把缺失缓存记录算作未缓存输入。
- 仅今日、本周、本月可用；加载中、加载失败与其他范围禁用入口。打开后后台刷新不改本次图片，重新打开取得最新已完成数据。两个辅助指标和费用开关只重绘快照。
- 两个辅助指标按所选顺序保存在当前浏览器，重开弹窗或刷新页面继续沿用；首次使用默认为缓存命中与输出。费用开关每次打开仍关闭，开启后的人民币／美元估算均四舍五入为整数，保留 `¥`／`$` 符号。
- 使用批准样板的 CSS／SVG foreignObject 在本地 Canvas 生成同一份 PNG，预览、保存、复制共用该 Blob。保存与复制成功静默，失败消息覆盖在预览井内，不改变弹窗尺寸。
- 本地打包与浏览器验收覆盖两种发行版；接入不自动发布或覆盖 GitHub Release。生产验收见[记录](../validation/2026-11-13-share-production/README.md)。

## 已批准的分享入口与弹窗

用户确认卡片基本达到预期，要求继续设计主界面入口和点击后的弹窗。入口位置已确定：**标题栏框体最右侧，在深浅色切换按钮右边**。复用旁边语言、皮肤、深浅色三个按钮的 `.theme-toggle` 外壳，保持尺寸、材质、圆角、阴影、间距及交互状态一致，仅为分享图标设置自身比例，不另做突出样式。最新图标选择为**向右上方转出的圆弧箭头**，用圆头与圆角连接呼应左侧按钮字符，替换原托盘上箭头外观；沿用 22.1px 图标和 2.04 描边宽度，64×38 按钮外壳及既有样式不变。

本轮弹窗采用**单列图片预览为主体**的布局，复用当前前端的弹窗、陶瓷凹槽和按钮规则。用户最终选择纯复制／保存流程：六个平台按钮与系统分享按钮均移除。底部左侧保留低对比度的 [GitHub 项目链接](https://github.com/Sylva1027/agent-usage)，右侧仅为 **“复制图片”“保存图片”**，GitHub 与两按钮底部对齐。主界面标题栏的分享生成入口继续保留，用于打开本弹窗。GitHub 仅是独立项目入口，不进入成品图片，也不替代尚未确定的新品牌。

弹窗只负责生成、预览、复制和保存 PNG；用户取得图片后自行选择分享渠道。不恢复社交平台跳转、系统分享面板或点击后二次展开的操作行。分享弹窗和放大原图窗口都不设置右上角关闭按钮，保留 Escape、点击遮罩关闭与焦点恢复。 每次进入放大原图时，视口顶部居中短暂显示“按 Esc 退出”／“Press Esc to exit”，3 秒后消失；提示浮于图片上方，不影响图片或窗口尺寸，不进入导出的 PNG。

此前六个平台入口并未传递生成图片：Telegram 错把公共 GitHub 项目链接放入分享消息，其余入口只是编辑器、首页或创作中心。随后曾制作系统 PNG 分享样板，并实际打开 Windows 分享面板，但用户现已撤回该方案。这些仅作为历史实现事实保留，均不是当前功能或待选方向；当前流程确定为复制／保存。

## 已确认的需求与场景

用户希望一键生成美观、有设计感、小块化且只展现关键信息的分享图片。**接收者以普通人为主**，无需熟悉看板、Token 明细或计价规则也能读出这段时间的使用情况。设计语言延续软件的陶瓷材质、主题色和可选角色。

当前已确认方向（含 2026-10-05 与 2026-11-13 反馈）：

- **信息重点：总用量为主数字，常用模型为第二重点，费用默认关闭且开启后仍为次要信息。** 使用通俗短标签和必要释义，不以专业指标数量体现信息量。
- **支持有限的半自定义。** 用户可以调整少量内容与表达，初始成品仍可直接保存；具体控件范围见下方建议。
- **主题跟随当前界面皮肤与深浅模式。** 浅色看板生成同皮肤浅色图，深色看板生成同皮肤深色图；配色与人物素材取同一模式。此前统一浅色的要求已撤回，分享弹窗不新增独立主题开关。
- **沿用 B 的人物比例与左侧同宽数据列。** 模型框体与下面两个辅助指标框体同宽，右侧是主要人物构图空间，不是独立裁切视口。人物作为全图底层装饰，可延伸到各框体下方和画布外部，由不透明框体遮住其下线条，最终只在整张图片边缘裁切。取消人物栏自身的矩形切口，不再以人物边界对齐框体。关闭人物时完全不绘制，仍保留对应主题色。
- **仅分享今日、本周、本月。** 跟随主页对应范围，其他范围的分享入口不可用；不删除主页的全部、自定义、最近范围或 5h/7d 功能。
- **不设置独立的文案标题及标题编辑。** 主卡左上以“今日／本周／本月模型用量”（英文“Model Usage（右上角 Today） / Model Usage（右上角 This Week） / Model Usage（右上角 This Month）”）合并周期与指标，不再在卡片顶部重复放周期和具体日期。成品也不常驻截止时分、时区或来源数；准确范围和统计依据保留在数据模型及现有主页详情中。此前个人化抒情标题的建议已撤回。

## 推荐画幅与内容

默认样稿推荐 **3:4 竖版、1080×1440**，比例均按宽:高记。它适合手机图文信息流，也便于将主指标和少量辅助卡片纵向排布；不将 16:9 横版作为默认分享图。

4:5（1080×1350）保留为紧凑对照样稿；1:1 可在后续需要极简分享时独立构图；9:16 留给全屏海报，不要求第一版同步实现。4:3 是横版，可另按横向内容需求评估。先确认默认 3:4 的效果，再决定格式数量。

内容按以下阅读顺序组织：

1. **主卡内的周期与指标标签。** 主卡左上按当前范围显示“今日模型用量 / Model Usage（右上角 Today）”“本周模型用量 / Model Usage（右上角 This Week）”或“本月模型用量 / Model Usage（右上角 This Month）”，每张只表达一次。仅支持这三个自然日历范围；全部、自定义、最近范围及 5h/7d 限额窗口均不提供分享。这里是数据标签，不是重新增加独立标题。具体日期、截止时分、时区、来源数不作为常驻图片元素；需要核对时回到主页详情查看。
2. **总用量主数字。** 主卡采用 05 的处理，保留缩小后的主字号，仍具有优先级，并与主卡高度、内边距及下部模块形成协调比例。中英文均用“128.40M”一类读数，不显示 `Tokens` 或另设单位角标。不将底层 Token 数换算为字数、代码行数、工作时长或效率；费用、环比与纪录不争夺主数字。
3. **五行模型读数与用量条。** 人物版位于下部左列，外框宽度与两个辅助指标一致，作为第二重点；简洁模式模型框沿用 A 的 760px 居中列。按所选区间的 Tokens 用量排序，展示最多五个模型，少于五个时自然收缩。删除“常用模型”和“用量占比”副标题，把空间用于数据。每行模型名左对齐、具体 M/B/T 用量右对齐，文字处于同一水平行和基线，不把数值另换到下一行；长模型名在名称区单行省略截断，保持字号与数值列完整；其下保留清楚的轨道与主题色填充条。沿用主页以榜首用量为统一尺度的比较逻辑，不能用相同长度、独立逐行归一或装饰长度伪造差异。模型区不显示百分比文字、排行序号或“其余模型”行，不另加切换配置。模型用量不能解释为调用频次、使用时长或效果排名。
4. **最多两个辅助小块。** 人物版在模型框下面沿同一列排列，左右边线、宽度和内容起点与模型框体对齐；简洁模式采用 B 的底部双框并列，整体左右边线与 A 的主框、模型框对齐。当前选定第三框为“缓存命中”、第四框为“输出”，二者采用 01 的表层标签与凹槽读数；允许从下方八项指标集合中替换。每块只放短标签、数值及必要单位，不以额外文案填满留白。M/B/T 与数字分离，以主卡为参考缩小字号、降低字重，不能和数字同字号同字重。模型总数覆盖整个所选区间，不能等于展示的五个模型数量。“缓存命中”继续表示缓存命中率，使用百分比，不改为缓存读取数量。
5. **可选费用。** 默认关闭；开启后在主框右下角作为小字次行呈现，不占用主数字、常用模型或两个辅助位置，不通过字号与强调色提升为主信息。使用独立定位，开启与关闭时主数字及框体几何保持不变，不为关闭状态保留空页脚。采用简短“API 估算” / “API estimate”标签，金额显示 `¥` / `$` 货币符号而非币种代码；机制、非账单口径与缺价明细放在现有主页详情，实际数据不足以提供可信金额时不伪装成完整总额。底层 USD/CNY 沿用当前显示币种和 FX 折算规则，不直接混加原币金额。

走势合并保持原总量、时间顺序与完整区间覆盖，并标注实际粒度；没有可比较上期时不展示环比或 New Record。零用量与数据缺失分开，未知缓存率显示“—”。用量在所有语言中统一按当前 M/B/T 规则换算和舍入，中文“百万”方案已撤回；百分比仅用于缓存命中率等本来就是比率的辅助指标。

首版推荐围绕主数字、常用模型和辅助小块收敛。迷你走势、纪录与环比属于后续内容候选，不因看板已有数据就自动加入分享图。

## 主题组合与人物构图

完整十角色范围下，共有 **42 种主题组合：classic 深浅两种 + 10 套皮肤 × 深浅两种 × 人物显示/隐藏**。这是主题模式与人物状态的组合数，辅助指标、费用等内容变化另计，不表示制作 42 套互不相关的版式。普通发行包覆盖 classic 两种，waifu 版覆盖全部 42 种；历史浅色样稿不代表深色组合已经验证。

人物沿用已选 B 的较大展示比例。下部左列为同宽的五行模型框和两个辅助指标，右侧作为人物主要可见区域；这个空间只指导位置与大小，不建立单独的裁切框。

图层关系沿用主页：背景最下，人物线稿置于背景之上、所有凸起框体与文字之下。线条可以穿过模块间隙，延伸到主卡、模型框和辅助框下方，也可以超出整张分享图的边缘；不透明框体自然遮住被压住的部分，最终只按导出位图边界裁切。不能先按右栏、某一框体的边线或人为矩形切掉人物，也不通过与模块对齐的遮罩/渐隐伪造裁口。人物不拉伸；面部与主要轮廓的可见性用构图调整，数据文字始终在上层清晰显示。

人物隐藏时不绘制残影、轮廓或人物水印；沿用该皮肤的主题色、表面冷暖和材质，形成隐性的身份表达。显示/隐藏共用稳定的信息层级；隐藏后按同一对齐和间距规则收回人物区域，避免留下空位。简洁模式已选 A 的前两框配 B 的底部双辅助框，保持相同信息量、画幅和读数层级，不直接把所有下部框拉到全宽，也不靠增加信息填空。此前“人物与主数字共同形成视觉中心”、全身优先、小角部人物和独立人物栏裁切均不再作为当前方向。

图片主题身份与模式取自本次打开时的当前 `skinId` 和 `theme`，色源与角色素材同取 `light` 或 `dark`。主界面为深色时生成同皮肤深色图，主界面为浅色时生成浅色图；预览、保存与复制保持同一结果，不为生成图片临时切换主看板，也不在分享弹窗另设主题开关。

颜色沿用届时生效的正式皮肤输入与公共派生规则，和[现行皮肤维护](../13-skins.md)保持同一来源；不冻结旧色值，也不维护另一套分享色板。当前选择器已开放十款角色；实际接入与检查继续核对注册表和资源，记录受测范围。

## 视觉与阅读尺度

## 工程实现

沿用批准样板的本地 SVG foreignObject → Canvas → PNG 路径，以同一渲染结果承担预览与输出，无新增运行依赖。正式 CSS 与可选人物图片内嵌到隔离 SVG，直接保留陶瓷材质、字体层级和浏览器单行省略行为。

- **纯数据投影与布局/绘制模块。** `public/share-card-data.js` 从正式汇总投影白名单，`public/share-card.js` 接受冻结结果、固定的皮肤与深浅模式输入及明确的展示选项。先绘背景与可出血的人物底层，再绘不透明框体、内槽、用量条与文字；人物层只受最终位图边界约束，不裁为独立右栏。模型投影取用量前五项，按当前 M/B/T 格式输出同排读数，并按共同比较尺度绘制用量条；先为右侧用量与间隙留宽，名称只在剩余区域单行省略截断，不修改模型投影中的完整规范身份；范围依据与成品展示字段分开传递，不访问原始日志或全局页面状态。绘图器只创建隔离 DOM、SVG 与 Canvas。
- **长名布局。** 正式 SVG 内的名称区可收缩并使用 `overflow: hidden`、`white-space: nowrap`、`text-overflow: ellipsis`，数值列不收缩，再由浏览器绘入 Canvas。截断不改变数据、模型排序、用量或条宽，不通过缩字或换行容纳长名。
- **页面控制。** `public/app.js` 负责固定汇总、皮肤身份和当前深浅模式、取得同模式配色、加载同模式角色、传入语言/货币/范围语义；`public/share-dialog.js` 负责弹窗状态、指标选择、文件保存与图片复制；范围和时区保留在数据快照，用于短文件名，不自动印到图片。使用 `skinAssetUrl`、`skinDisplayParams` 和本地素材，不读取已删除的内嵌资源全局变量。主题身份与图片模式明确传递，配色从同模式的正式色源取得，不能短暂切换主界面来取色。
- **样式与入口。** 在 `public/index.html`、必要的 `public/share.css` 和 `public/i18n.js` 中接入同款控件、固定位置的失败反馈、焦点恢复与可访问名称；不增加保存或复制成功提示。新文案遵守现有 i18n 测试。
- **色源映射。** 直接内嵌正式 CSS，并使用同模式 `paletteDeclarations`；CSS 阴影、渐变与陶瓷材质由浏览器渲染，不把 CSS 阴影字符串误当 Canvas 色值。
- **数据白名单。** 只收汇总数字、必要模型名、时间、指标标签与限定说明；路径、来源目录、会话 ID、正文、原始事件不进入分享模型，不为已移除的标题编辑增加自由文本字段。

不为了出图重新扫描日志、另建统计规则、增加账号或上传服务。第一版不做公开链接、二维码、GIF、任意长图或独立色板；这些是推荐范围，不是永久排除后续需求。辅助指标选择已按用户追加要求持久化。浅色与深色图片均进入本版范围，直接跟随主页模式，不新增分享主题配置。
