# 路线图与项目边界

更新：2026-11-11。具体状态见[任务清单](02-tasks.md)，本页只维护产品方向与范围。

## 产品目标

Agent Usage 在本机读取 Codex、ZCode、DSH、OpenCode、Claude Code、WorkBuddy 和项目日志，按时间、渠道、模型与仓库展示 Token 用量及 API 等价费用。原始日志和索引留在本机，不上传会话正文。

主程序继续使用 Node.js、SQLite 和浏览器原生 JavaScript，没有生产 npm 依赖。Windows 原生助手负责来源变化证明和归档读取锁，普通运行不需要 Rust 工具链；旧语言／数据库原型已[归档](archive/2026-11-11-experiments/README.md)。

## 已有能力

- 六来源发现与导入、增量索引、历史保留、冻结快照及恢复。
- 日期范围、Codex 限额窗口、周期对比、搜索、排序和中英文界面。
- 有效价目、自动更新、手动覆盖、混币汇率、缺价与免费规则。
- 深浅主题、十款角色皮肤、简洁模式及独立配色工作室。

页面面向桌面鼠标键盘操作，以 16:9 大屏为基准；窗口缩小、侧栏和并排使用保持操作可达。分享图片的手机阅读要求不扩展为整套页面的手机产品需求。

## 后续方向

当前待实施的是[追加需求](plans/2026-11-11-post-refactor-additions-plan.md)；[分享图片](plans/2026-10-03-mobile-share-card-consolidated-plan.md)已接入标准版与 waifu 版主页。技术栈替换、性能大矩阵与 TPS 实装没有因文档整理重新启动。

TPS 与旧独立 HTML 导出已经退出产品。TPS 离线研究保留在[研究盒子](archive/2026-11-01-tps-research.md)，研究代码存在不代表产品功能可用。

## 持续边界

- 费用是 API 等价估算，不是账单或套餐扣费；不通过缺失日志推算请求。
- 原始事实与派生缓存分开处理，清理和升级不得丢弃已从上游消失的历史。
- 来源字段、缓存 TTL、缺价与平台能力依照已验证内容表达；未证实的语义不靠猜测补齐。
- 新增需求先确定行为与验收范围，完成后把有效规则写入专题，原施工计划转入归档。
